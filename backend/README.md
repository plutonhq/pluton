# @plutonhq/core-backend

Public open-source backend for Pluton, originating from `plutonhq/pluton` and
extended independently in this self-hosted fork. Existing package names and
Apache-2.0 attribution are preserved for compatibility. No proprietary edition is
required. See the root README and `docs/ARCHITECTURE.md` for tests/deployment;
operator documentation is bundled at `/docs` in the application.
