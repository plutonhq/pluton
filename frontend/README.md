# @plutonhq/core-frontend

Public React components and utilities for Pluton, originating from `plutonhq/pluton`
and extended independently in this self-hosted fork. The existing package namespace
and Apache-2.0 attribution remain intact. The bundled Bahasa Indonesia documentation
portal lives in `src/docs`; validate with `pnpm test:docs` and build with `pnpm build`.
No commercial license or separate documentation service is required.
