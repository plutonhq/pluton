# S3-compatible dan storage lokal

## Dukungan yang ada

Rclone provider registry mempunyai local filesystem dan S3 settings untuk local managed operations. Dukungan form/provider bukan hasil acceptance pada semua vendor, region, bucket policy, atau endpoint. Integrasi S3 DRC tertentu belum dibuktikan oleh task ini.

Managed outbound Remote Agent belum menerima S3 atau local destination payload. Gunakan SFTP untuk jalur tersebut; jangan menyetel provider berbeda lalu mematikan validator. Legacy registration awal dibatasi repository filesystem lokal yang dapat dibaca server.

## Local destination

Path local berarti filesystem pada execution host/container. Volume mount, permission non-root, serta pemisahan source/repository adalah pekerjaan administrator. Root filesystem read-only Docker tidak membuat destination arbitrary dapat ditulis. Jangan mount live source writable sebagai solusi permission.

## S3-compatible

Operator mengatur endpoint, region, access scope, certificate trust, bucket isolation, dan biaya/retention storage. Jangan menganggap object-store lifecycle policy aman bila menghapus blob yang masih dirujuk snapshot. Test init, backup, exact restore, dan credential failure pada bucket disposable sebelum acceptance workload.

## Capacity

Storage provider usage dan logical Restic stats berbeda. Untuk physical usage gunakan pengukuran provider/filesystem yang benar-benar tersedia. Jangan mengekstrapolasi disk growth dari New Files atau menampilkan guessed deduplication ratio.
